# LLM Evaluation Suite

Projeto desenvolvido como desafio da **Sprint 2** do estágio **AWS AI FDE Driven Quality Engineering**, com foco na implementação de uma suíte de testes para avaliação da qualidade e confiabilidade de aplicações baseadas em **Large Language Models (LLMs)**.

A suíte utiliza métricas e técnicas de **LLM Evaluation** para analisar diferentes aspectos das respostas geradas pelos modelos, incluindo **Faithfulness, Answer Relevancy, Hallucination** e **GEval (LLM-as-a-Judge)**.
